
# Social Media Sentiment Analysis

## 1. Project Overview

This project focuses on analysing social media sentiment using Python, SQL, Microsoft Excel, and Tableau. It involves exploring sentiment data, performing data analysis, querying records, and creating visualisations to understand sentiment patterns and comparisons across entities.

The project demonstrates a multi-tool data analytics workflow, from data exploration and preparation to querying, reporting, and visualisation.

## 2. Objectives

- Explore and understand social media sentiment data.
- Analyse the distribution of sentiment categories.
- Compare sentiment patterns across different entities.
- Examine tweet volume and tweet length.
- Create visualisations to communicate analytical findings.
- Practise using multiple tools in a data analytics workflow.

## 3. Dataset

The project uses the following CSV files:

- `twitter_training.csv` – Training dataset used for exploration and model-related work.
- `twitter_validation.csv` – Separate validation dataset used during the project.

The data contains social media text and associated sentiment labels and entities.

## 4. Tools and Technologies

- **Python:** Data preparation, exploratory data analysis (EDA), and machine-learning-related work.
- **SQL (MySQL):** Data querying, aggregation, and sentiment analysis.
- **Microsoft Excel:** Data analysis, summaries, and visualisations.
- **Tableau:** Interactive data visualisation and dashboard development.

## 6. Key Areas of Analysis

The project examines:

- Distribution of sentiment categories.
- Sentiment patterns across entities.
- Relative percentage of sentiment categories.
- Tweet volume and entity-level comparisons.
- Average tweet length.
