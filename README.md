# Social Media Sentiment Analysis

## Overview

This project focuses on analysing social media sentiment using Python, SQL, Microsoft Excel, and Tableau. It explores sentiment patterns across entities, examines tweet volume and text length, and presents analytical findings through queries, spreadsheet analysis, and visualisations.

The project demonstrates practical experience in data exploration, data analysis, SQL querying, and data visualisation.

## Objectives

- Analyse the distribution of sentiment categories.
- Compare sentiment patterns across entities.
- Examine tweet volume and tweet length.
- Use multiple tools to analyse and visualise data.
- Communicate findings through structured analysis and visualisations.

## Tools and Technologies

| Tool | Purpose |
|---|---|
| Python | Data exploration, preparation, and model-related work |
| MySQL | SQL queries, aggregations, and comparisons |
| Microsoft Excel | Data analysis, summaries, and charts |
| Tableau | Data visualisation and dashboards |

## Dataset

The project uses two main CSV files:

- `twitter_training.csv`
- `twitter_validation.csv`

These datasets contain social media text, associated entities, and sentiment labels.

## Project Structure

- `Python/` – Python notebooks and related files
- `SQL/` – SQL scripts and queries
- `Excel/` – Excel analysis and visualisations
- `Tableau/` – Tableau workbooks and visualisations
- `Documentation/` – Detailed project documentation

## Key Analysis Areas

- Sentiment distribution and percentages
- Sentiment comparisons across entities
- Tweet volume and average tweet length
- Visual exploration of sentiment patterns
